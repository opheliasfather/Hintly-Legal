# Hintly Legal

Public legal pages for the **Hintly** iOS app (Bundle ID: `com.hintly.six11`).

## App Store Connect URLs

After GitHub Pages is live:

- **Privacy Policy:** https://opheliasfather.github.io/Hintly-Legal/privacy-policy.html
- **Terms of Use:** https://opheliasfather.github.io/Hintly-Legal/terms-of-use.html

## Languages

English, Türkçe, Français, Deutsch, Español, Italiano.

## Publish

1. Create a public GitHub repo named `Hintly-Legal`.
2. On GitHub: **Settings → Pages → Build and deployment → Branch: `gh-pages` / `/ (root)`**.
3. Push to `main` (workflow publishes to `gh-pages` automatically).
